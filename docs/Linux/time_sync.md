# 时钟的来源，晶振


我们使用的外部晶振

**XO晶振**（**Crystal Oscillator**）是一种最常见的时钟源器件，指的是：

> **使用石英晶体（Quartz Crystal）与一个基本振荡电路（如反相器、电容、电阻）封装在一起的标准晶体振荡器**。
> 

无源晶体（Crystal）2 个（无电源引脚）
