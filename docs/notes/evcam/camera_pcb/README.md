# 共模

共模信号是指在 **两根导线** 或 **多个信号线** 上 **相同的电压变化**。

在差分信号传输（如USB、HDMI、Ethernet等）中，两个信号线上的电压变化是相同的，这种变化会被称为共模信号。

# 如何做ESD

**ESD（静电放电）** 是指不同电势物体之间由于静电积累，在接触或接近时发生的 **瞬态高电压放电** 现象。它可能造成电子设备损坏、信号干扰，甚至引发安全事故。

# 焊锡膏参数

## 球形

| 粉末等级 | 颗粒直径范围（µm） |
| --- | --- |
| Type 1 | 75-150 |
| Type 2 | 45-75 |
| Type 3 | 25-45 |
| Type 4 | 20-38 |
| Type 5 | 15-25 |
| Type 6 | 5-15 |
| Type 7 | 2-11 |
- **Type 3、Type 4**：常用于**SMT（表面贴装技术）**，适用于一般PCB焊接。
- **Type 5、Type 6**：适用于**微间距封装（如BGA、CSP、QFN）**，更精细的焊接需求。
- **Type 7 及以上**：用于超精密焊接，如**微电子封装**。

✅**Type 3（25-45µm）**：适用于**普通SMT**，比如**0.5mm间距以上的器件（QFP、SOP、THT）**，性价比高。

✅**Type 4（20-38µm）**：适用于**0.4mm~0.5mm间距的BGA、QFN、CSP**，目前较为主流。

✅**Type 5（15-25µm）**：适用于**0.3mm以下超细间距封装**，如**01005封装、小间距BGA**。

✅**Type 6（5-15µm）或更细**：适用于**超精密封装**（如芯片级封装CSP、Mini LED、Micro LED），但存储要求高，易氧化。
