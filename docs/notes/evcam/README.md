# v4l2 

v4l2 是什么

> 我第一次接触 v4l2，是从便宜的 USB 相机开始的。当时用过一个 v4l2 工具，那些相机延时很大，性能也一般，我便以为它只是给廉价摄像头准备的垃圾开源框架。
>
> 后来才明白，延时大，是因为传出来的已经是编码后的视频。这些摄像头是 USB 2.0，raw 图根本回传不过来，带宽不够，只能靠编码把数据压下去。视频会议对实时性和时间戳几乎没有要求；而我的场景偏偏很看重这两点，偏见也就这么来了。
>
> 至于性能差，编码是一层原因，CMOS 本身差是另一层。
>
> 现在开始学怎么写 Linux camera driver，我才知道 v4l2 是 Video for Linux 2，是 Linux 上的一套多媒体框架。
